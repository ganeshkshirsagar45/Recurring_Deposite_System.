# 💰 Recurring Deposit System

A full-stack **Recurring Deposit (RD) Management System** designed to provide a simple and user-friendly platform for managing recurring deposit accounts, users, and investment-related information.

## 🚀 Project Overview

The Recurring Deposit System provides a web-based platform with separate user and administrative functionalities. It includes authentication, RD account registration, user management, services, contact functionality, and nominee information.

## ⚙️ How to Run

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Open the `backend` project in **Spring Tool Suite / Eclipse** and run the Spring Boot application.

### Database

Create the required PostgreSQL database and configure the database connection details in the backend configuration.
